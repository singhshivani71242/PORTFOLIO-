## 🌐 About the Project

This is my personal portfolio website, designed to showcase my skills, education, projects, and frontend-development journey in a clean and interactive interface.

The website features a **dark UI with gold accents**, responsive grid layouts, project cards, a sticky profile sidebar, and section-based navigation.

---

## 🚀 Features

* 🎨 Clean dark-themed UI with gold highlights
* 👩‍💻 Personal profile section
* 📱 Responsive layout
* 🧭 Navigation between About, Skills, Education, and Portfolio
* 🛠️ Skills showcase with technology icons
* 🎓 Education timeline
* 💼 Project showcase cards
* ✨ Hover animations and interactive UI elements
* 🔗 Social/contact section
